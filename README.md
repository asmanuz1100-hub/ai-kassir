## Икки админ (1C ёки Hisobchi AI билан интеграция йўқ)

Бот энди `ADMIN_TELEGRAM_IDS` ўзгарувчиси орқали бир нечта админни қўллайди. Render → **AI Kassir test → Environment** бўлимига ўтинг, `ADMIN_TELEGRAM_IDS` ни админларнинг **рақамли Telegram ID'лари, вергул билан ажратилган** шаклда киритинг ва сақлаб deploy қилинг. ID'ларни GitHub кодига қўшманг. Агар `ADMIN_TELEGRAM_IDS` киритилмаган бўлса, дастур олдинги ягона `ADMIN_TELEGRAM_ID` ни ўқийди; бундай ҳолатда фақат битта админ ишлайди.

Янги версия ишга тушганда админ рўйхати муҳит созламасига мувофиқ янгиланади. Оддий кассирларнинг мавжуд рухсатлари сақланади. `/allow <TELEGRAM_ID>` кассирни қўшади, админни эмас.

**Интеграция ҳозирча ўчирилган:** Hisobchi AI, 1C ёки бошқа ботнинг репозиторийсига, маълумотлар базасига ёки хизматига тегилмайди.

## RubaiSTT v2 овозни таниш — алоҳида сервер талаб қилинади

RubaiSTT v2 Medium учун алоҳида, шахсий ва аутентификацияланган сервер коди `rubai_service/` папкасида тайёр. Ботнинг унга уланиш коди `rubai_client.py` да. Модел оғирлиги тахминан 3.06 GB, шунинг учун уни Render Free'нинг 512 MB RAM хизматида ишга тушириб бўлмайди. **Модел ҳали ҳеч бир ташқи серверга жойлаштирилмаган; ҳозир ботда Groq ишлашда давом этади.**

RubaiSTT сервери ўзингизнинг компьютерингизда ёки етарли RAM/GPU ли алоҳида хостда ишга тушгач, AI Kassir Render Environment'га `RUBAI_ASR_URL` (хусусий HTTPS манзил) ва `RUBAI_ASR_TOKEN` (ўша сервердаги алоҳида махфий токен) бирга киритилади. Бу калит Groq ёки Telegram токени эмас. Шунда RubaiSTT аудиони таниш учун ишлатилади, Groq эса фақат танилган матндан операцияни ажратиш учун қолади. Қадамлар: [Rubai service deployment](rubai_service/README.md).

## Тест базаси ва овоз

Жорий `TEST_MODE=1` ҳолатида бот алоҳида вақтинчалик SQLite файлга ёзади; Render қайта ишга тушганда ёки deploy бўлганда ёзувлар йўқолиши мумкин. Ҳақиқий касса операцияларини киритманг. `/balance` бошланғич касса қолдиғи эмас, фақат тест кирим-чиқимларининг йиғиндиси.

Овозли хабарни таниш учун ҳозир `GROQ_API_KEY` ишлатилади. RubaiSTT сервери алоҳида ишга туширилиб улангандан кейингина унинг овозни таниш тизими фаоллашади. AI талқини учун ҳам Groq ишлатилади; API калит бўлмаса матн учун чекланган қоидали парсер ишлайди. AI хато қилиши мумкин: ҳар бир операцияни тасдиқлашдан аввал сумма, валюта, категория ва йўналишни текширинг.

## Кейинги босқич

Ҳақиқий молиявий ҳисобдан олдин фақат AI Kassir учун алоҳида доимий база, захира нусхаси, бошланғич қолдиқ, кун ёпилиши ва тузатиш аудити талаб қилинади. Мавжуд Hisobchi AI базасини қайта ишлатманг. Render бир аккаунтда иккинчи бепул PostgreSQL базасини яратишга рухсат бермаган; пуллик тарифни фақат алоҳида тасдиқдан сўнг танлаш керак.
